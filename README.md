# صلاحية: نموذج أولي

قائمة ذكية لتراخيص الشركة وشهاداتها واعتماداتها وعضوياتها ومواعيدها، مع تنبيهات قبل الانتهاء.

نسخة تجريبية للاختبار فقط:
- لا تُرسل رسائل بريد حقيقية، ورمز الدخول يظهر على الشاشة.
- تُحفظ البيانات في متصفح الجهاز فقط ولا تُرسل إلى أي خادم.
- البيانات النموذجية لشركة افتراضية.
